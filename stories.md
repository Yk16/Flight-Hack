# Users
 - Admin - Global Supervisor
 - User - Unified single account for Everyone (starts as Customer, can upgrade privileges)

# <Multitenant>

# Admin
- CRUD all users
    - Change password of user
    - View user profile
    - Suspend or Block users
## user documents
- Verify user documents and approve "Owner" or "Provider" privilege upgrades

# Admin Platform Management
- Monitor and manage all houses
- Monitor service provider listings
- View platform payments and revenue
- Resolve disputes or reported reviews

# User (Unified Core Account)
- Register & Login (One universal login using OTP, Password, OAuth)
- Manage Profile (Avatar, Basic Info)
- Setup Flatmate Profile (Budget, Lifestyle, Preferences)
- Browse & Search Houses (Filter by Rent, Type, Amenities, Location)
- Send Booking Requests for Houses
- Review & Sign Rental Agreements
- Process Payments (Rent, Deposit, Service fees)
- Browse & Book Service Providers (Maids, Cooks, Furniture, etc.)
- Chat with Owners, Potential Flatmates, and Service Providers
- Write Reviews (Rate Houses, Owners, and Service Providers)
- View Audit Logs and Login History

## Account Upgrades (Settings)
- Submit KYC Verification (Aadhaar, PAN)
- Opt-In to become a **Flat Owner** (requires document verification)
- Opt-In to become a **Service Provider** (requires document verification)

# Activated Privileges: Vendor (Flat Owner)
*Unlocked via Settings once Admin verifies Owner request*
- CRUD Houses / Properties
    - Set rent, deposit, features, and photos
- Manage House Availability Status
- View and Manage Tenant Booking Requests (Accept / Reject)
- Draft & Counter-Sign Rental Agreements
- Track and Receive Rent/Deposit Payments

# Activated Privileges: Vendor (Service Provider)
*Unlocked via Settings once Admin verifies Provider request*
- CRUD Service Listings
    - Set pricing model (per month, one time), price, and description
- View and Manage Service Booking Requests (Accept / Complete)
- Receive Payments for Services
